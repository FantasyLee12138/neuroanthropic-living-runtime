remote-terminal

Stateless relay client for observer sessions

This stateless relay client 这个页面只做最轻的接入层：连接 observer base URL，启动或恢复 session，发送 user_turn / control_command， 并从 /web/session/state 与 /web/session/events 读取 transcript 与事件。 页面不保存运行时真相，也不写本地持久化。

Transcript

只渲染 observer 回填的 transcript_lines，不在浏览器里发明第二份会话状态。

Controls

连接后会从 /web/session/state 回填 transcript，并用 /web/session/events 持续跟进事件。

Observer events

SSE / once-poll 的原始事件流。这里保留的是服务端事件，不做本地状态推断。

Session state

来自 /web/session/state 的当前会话快照，仅用于渲染。
