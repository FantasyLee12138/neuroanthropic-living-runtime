# NALR 1.6 Release Notes

## Summary

`1.6` 的主题不是继续堆观察接口，而是把 Workbench 变成默认前台，并让主体、意义、主动性真正进入 runtime 闭环。这个版本同时修掉了一个实际 front door 问题：从 `Open_NALR_Workbench.command` 打开时，observer 现在会先同步最新 Workbench 产物，避免 `/dashboard` 继续展示过期页面。

从 release gate 的角度看，`1.6` 现在明确分成两条并列门槛：
- `release_frontdoor`
- `release_subjectivity`

## What Shipped

### 1. Workbench 前台改成聚合读模型

这组交付属于 `release_frontdoor`。

- `/dashboard` 默认进入新的 Workbench，而不是旧的堆叠观察页
- Workbench 通过 `/workbench/read-model` 和 `/workbench/round/{id}` 读取聚合数据
- 前台不再依赖旧的多接口补拉和 legacy fallback 逻辑

### 2. subject / meaning / agency 进入真实闭环

这组交付属于 `release_subjectivity`，并扩展成六个 namespace：
- `release_16.subjectivity.single_truth`
- `release_16.subjectivity.memory`
- `release_16.subjectivity.competition`
- `release_16.subjectivity.history`
- `release_16.subjectivity.recovery`
- `release_16.subjectivity.drift`

- `purpose_memory` 不再每次同步都从头重建，而是会和 persisted state 对齐
- `meaning_system` 会回读 `purpose_memory`，不再只是页面上的启发式摘要
- `subject_kernel` 在当前目标退场后仍能从已持久化的目的记忆中维持连续性
- `agency_loop` 会把计划任务纳入 backlog 与预算，并在到期时优先执行
- read-model 和 round detail 现在还会暴露 `state_truth / memory_evidence / competition_evidence / continuity_evidence`

### 3. 首屏与分析阅读流重做

- 首页围绕“稳不稳、为什么继续、下一步看哪层”组织信息
- 分析页固定为左侧轮次筛选、中间主阅读流、右侧证据抽屉
- 趋势图、脑流阶段、未采纳路径、时间线和原始数据分层更明确
- 中文模式下主标签统一为中文优先，减少英文残留和内部术语泄漏

### 4. 启动链补上最新产物同步

- `Open_NALR_Workbench.command` 最终走 `alive-observer foreground`
- observer 前台启动前会同步 `apps/workbench/src -> apps/workbench/dist`
- 用户再从命令打开时，不会因为 `dist` 过期而看不到最新页面

## Operator Notes

- `/dashboard-legacy` 仍保留，作为回退页，不再是默认入口
- 如果只想看旧页，需要显式访问 `/dashboard-legacy`
- `apps/workbench/scripts/build.mjs` 仍可手动执行，但不再是必须前置步骤
- release 验收时需要同时检查 `acceptance_report.release_16.release_frontdoor` 与 `acceptance_report.release_16.release_subjectivity`

## Known Gaps

- 单实例服务状态仍是 `partial`
- self-hosted bounded acceptance 已有可复现 `pass`，但它不等于真实长跑
- 真实 24h soak 还没有形成 release 证据
- `release_subjectivity.recovery` 与 `release_subjectivity.drift` 现在可以在 bounded probe 中达到 `pass`，但未宣称真实 24h soak 完成
- Hermes-inspired skills / cron 治理仍停留在后续 hardening 范围，不计入本轮已完成项
