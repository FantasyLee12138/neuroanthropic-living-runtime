# NALR 1.5 Self-Hosted Deployment

## 目标

1.5 默认支持单实例自托管，不以多用户 SaaS 为首版目标。

## 推荐部署形态

- 一台服务器
- 一个 NALR 实例
- 一个 observer/runtime 服务
- 浏览器通过 `/dashboard` 访问 workbench

## 启动方式

```bash
cd /Users/fantasylee/类脑架构
./alive-observer start --no-browser --host 0.0.0.0 --port 8765
./alive-observer status
```

## 运维要求

- `/service/status` 必须可读
- 服务日志保留在 `.alive/observer-service`
- 支持 `status` / `logs` / `stop` / `restart`
- 异常退出后能被识别并重新拉起

## Bounded Long-Run 验收

- 保持服务连续运行
- workbench 可访问
- `autonomy`、`initiative`、`monologue` 状态持续可读
- 长时运行报告写入 `docs/testing/`

当前已有一份明确标注为 `release_15.bounded_long_run` 的阶段性证据：

- [`docs/testing/2026-04-08-self-hosted-equivalent-longrun.md`](/Users/fantasylee/类脑架构/docs/testing/2026-04-08-self-hosted-equivalent-longrun.md)

它证明 release acceptance path 已经存在，但不冒充真实 24h soak。

## 验收入口

可先用 1.5 acceptance runner 逐组执行：

```bash

python3 /Users/fantasylee/类脑架构/scripts/acceptance_15.py --run --group observer
python3 /Users/fantasylee/类脑架构/scripts/acceptance_15.py --run --group runtime
python3 /Users/fantasylee/类脑架构/scripts/acceptance_15.py --run --group self-hosted
```

## 已知边界

- 当前是单实例模式
- `release_15.bounded_long_run` 与 acceptance-report 已有，但正式 24h soak 仍未完成
- 多租户、权限隔离和多用户接入不属于 1.5 首发范围
