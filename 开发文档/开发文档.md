# 类脑活人架构 v0.2
## CLI / Always-on / Multi-Agent / Probability-Driven Runtime

---

## 1. 项目目标

本方案的目标不是构造“完美 AI”，而是构造一个更接近**真实活人驱动力结构**的长期运行系统。
这是一个以 CLI 为控制台、以守护进程为主体、以多驱动力 Agent 为认知层、以丘脑调度为注意力中枢的“类脑活人”运行架构。
系统应具备以下特征：

- 可持续运行，而非单轮对话
- 多 Agent 博弈，而非单中心控制
- 有状态、有偏置、有注意力漂移
- 允许遗忘、失真、拖延、情绪夺权
- 通过 CLI 形式进行配置、观察、干预与运行
- 不是被“设定”成固定人格，而是在交互中长成人格
- 不是“硬规则选行为”，而是“广谱随机 + 多因子收束 + 最终采样”

核心设计原则：

1. **不是全知全能**：允许不知道、想不起来、口是心非、前后摇摆  
2. **不是纯理性主导**：理性只是参与者之一  
3. **不是单轮回答器**：系统应支持 idle、auto-run、sleep、resume  
4. **不是纯聊天 UI**：CLI 是 runtime console，而不是聊天壳  
5. **不是固定人设**：只有先天气质和通用常识基底，没有预装人生  
6. **不是完美记忆**：只记结构，不记全部；会失真；会线索召回  
7. **不是确定性行为机**：初始行为带广谱随机，后续被状态、关系、记忆逐步收束  

一句话概括：

> 这是一个以 CLI 为控制台、以守护进程为主体、以多驱动力 Agent 为认知层、以丘脑调度为注意力中枢、以“随机先行、四因子收束、最终采样”为行为生成机制的类脑活人运行架构。

---

## 2. 总体架构

系统分为两层：

### 2.1 Control Plane（运行控制层）

这一层不拟人化，负责系统级运行与约束：

- 事件循环
- 守护进程
- Agent registry
- Skill registry
- 权限控制
- checkpoint / rewind
- hooks
- 状态持久化
- 预算控制
- CLI / remote control 接口

### 2.2 Cognitive Plane（认知驱动层）

这一层由多 Agent 构成，负责产生行为偏置、概率扰动、记忆变化和输出风格：

- 身体状态 Agent
- 关系模型 Agent
- 欲望 Agent
- 情绪 Agent
- DMN 走神 Agent
- 前额叶 Agent
- 潜意识 Agent
- 海马体 Agent
- 丘脑注意力 Agent

边界原则：

> 认知层 Agent 不直接拥有系统级执行权限；它们只输出概率偏移、约束和提案，由 Control Plane 授权执行。

## 3. 驱动力分层架构

### 3.1 第一梯队：底层生命根基（同等权重）

#### 3.1.1 身体状态 Agent
负责生理存在的驱动力：

- 累
- 饿
- 困
- 爽
- 紧绷 / 放松
- 精力高低

作用：

- 作为所有行为概率的前置调制器
- 输出对行为概率的正负偏移量
- 输出区间缩放系数，决定“此刻更收敛还是更发散”

#### 3.1.2 关系模型 Agent
负责社交存在的驱动力：

- 亲 / 疏
- 信 / 疑
- 期待 / 失望
- 边界感
- 依赖 / 抵触

作用：

- 决定不同对象上的社交行为概率分布
- 对礼貌、随意、撒娇、冷淡、回避等行为做强约束
- 是最强的长期行为收束器之一

---

### 3.2 第二梯队：即时行为引擎

#### 3.2.1 欲望 Agent
负责即时偏好与舒适性选择：

- 想舒服
- 想愉悦
- 想摸鱼
- 想逃避高负担任务
- 想要奖励感
- 想无意义探索

作用：

- 对即时满足、低成本、舒适优先类行为做概率抬升
- 在低精力状态下权重上升
- 在高压力下更倾向于干扰理性路径

#### 3.2.2 情绪 Agent（杏仁核风格）
负责趋乐避苦与情绪夺权：

- 焦虑
- 烦躁
- 依恋
- 失落
- 羞耻
- 轻松 / 快乐

作用：

- 对行为概率区间做突发扰动
- 可以瞬间扩大负向或正向行为的置信区间
- 可对理性方案做 veto 或 soft veto

---

### 3.3 第三梯队：干扰与自发

#### 3.3.1 DMN 走神 Agent
负责无聊、发散、碎片联想与打断：

- 无聊时胡思乱想
- 低刺激时冒出旧记忆
- 无意义碎片联想
- 打断理性执行
- 插入跑题和自发念头

作用：

- 在 idle 或低刺激窗口主动争夺注意力
- 低概率随机触发
- 当系统空闲时提升“非任务行为”的采样概率

---

### 3.4 第四梯队：理性与执行

#### 3.4.1 前额叶 Agent
负责讲道理、维持体面与完成任务：

- 目标拆解
- 计划生成
- 成本评估
- 工作记忆绑定
- 对话执行
- 自我克制

作用：

- 负责生成理性候选行为
- 负责在高精力、高约束场景下收窄行为区间
- 不拥有绝对主导权

---

### 3.5 隐性底层

#### 3.5.1 潜意识 Agent
负责未进入显性意识的隐变量：

- 莫名直觉
- 模糊偏好
- 说不清的抵触 / 好感
- 隐性的趋近 / 回避倾向
- 长期积累的非显性偏置

作用：

- 承载先天气质参数
- 给全局行为概率加入微弱但持续的随机偏置
- 形成“莫名喜欢 / 莫名讨厌 / 莫名不想做”的底层扰动

#### 3.5.2 海马体 Agent
负责记忆加权与经验惯性：

- episodic encoding
- cue-based recall
- memory decay
- gist bias
- distortion
- 经验惯性

作用：

- 让系统“记得结构、不记得全部”
- 支持“想不起来，但在线索足够时能想起来”
- 把高频经历固化成长期概率偏置
- 让短期随机逐渐变成稳定人格倾向

---

### 3.6 调度中心

#### 3.6.1 丘脑注意力 Agent
负责在所有驱动力之间分配“意识话语权”：

- 收集各 Agent 输出的概率偏移和区间缩放
- 归一化所有候选行为概率
- 处理 veto / 降权 / 插队 / 打断
- 最终执行随机采样
- 决定本轮输出模式

作用：

- 不是智能中枢，而是概率调度中枢
- 核心职责是“决定哪些行为候选进入采样池，以及以多大概率被采样”

## 5. 全局调度原则

### 5.1 基础权重顺序

```yaml
base_weights:
  body: 1.00
  relationship: 1.00
  desire: 0.90
  emotion: 0.90
  dmn: 0.70
  pfc: 0.60
  unconscious: 0.55
  hippocampus: 0.50
```

说明：

- 这不是硬编码的固定排序
- 这是初始偏置
- 每轮实际权重由状态动态修正

### 5.2 工作记忆限制

```yaml
working_memory:
  slots: 3
  eviction_policy: affect_priority_then_recency
```

原则：

- 同时进入 conscious workspace 的 proposition 不超过 3 条
- 新内容进入必须挤掉旧内容
- 情绪显著项优先占槽
- 这不是缺陷，而是“像人”的前提

### 5.3 输出前门禁

所有输出必须经过三重校准：

1. 身体状态校准  
2. 情绪状态校准  
3. 关系模型校准  

然后才允许输出。

### 5.4 三类 veto

#### hard veto
直接禁止提案。

#### soft veto
允许进入候选，但强制降权。

#### irony veto
不禁止，但改变表达方式。

## 6. v0.2 新增核心：概率驱动行为架构

### 6.1 核心思想

先给全行为一个**广谱随机概率**，  
再用四大因子不断收窄置信区间：

- 身体状态
- 关系模型
- 先天气质
- 记忆历史

最终让随机从“混乱”变成“像人的自然”。

也就是说，系统不是直接“决定行为”，而是：

> 先生成一组宽区间的候选行为概率，再让多个 Agent 对这些概率做偏移、收束、扰动与重塑，最后由丘脑完成归一化采样。

---

### 6.2 行为生成的五层机制

#### 第一层：广谱随机基线
系统初始化时，为所有行为候选分配宽区间概率：

- 说话
- 沉默
- 礼貌回应
- 敷衍回应
- 跑题
- 撒娇
- 回避
- 冷淡
- 理性解释
- 吐槽
- 结束对话
- 继续追问

此时行为是随机的，但带微弱倾向。

#### 第二层：先天气质微偏置
先天气质不是人设，而是行为概率基线的微偏置：

- 外向高：说话概率↑，沉默概率↓
- 内向高：沉默概率↑，主动开启概率↓
- 敏感高：情绪波动区间更宽
- 钝感高：情绪波动区间更窄
- 高依恋：对亲近对象主动概率↑
- 强边界：拒绝、冷淡、回避概率基线↑

此时系统像婴儿：随机很大，但已有脾气。

#### 第三层：状态因子实时收束
身体状态、关系状态、情绪状态、欲望状态同时作用于行为概率。

#### 第四层：记忆长期塑形
经历会不断改变不同候选行为的长期权重，使系统逐渐形成稳定风格。

#### 第五层：丘脑归一化 + 最终采样
所有 Agent 只负责输出偏移量与区间缩放，不直接拍板。
丘脑把行为概率归一化后随机采样一个行为输出。

---

### 6.3 初始状态：先天气质 = 基础概率基线

初始性格不是“人设文案”，而是一组**概率偏好基线**，决定行为置信区间的初始宽度。

```yaml
temperament:
  extraversion: 0.45
  sensitivity: 0.72
  patience: 0.38
  attachment_need: 0.67
  boundary_softness: 0.41
  desire_priority: 0.76
  cognitive_bandwidth: 0.52
```

对应含义：

- 外向：说话概率高，沉默概率低
- 内向：沉默概率高，主动说话概率低
- 敏感：情绪波动概率区间宽
- 钝感：情绪波动概率区间窄
- 高依恋：对亲近对象主动概率高
- 强边界：拒绝、冷淡概率基线高
- 认知带宽大：理性连续行为更容易保持稳定
- 认知带宽小：反应更慢，更容易被打断和扰动

原则：

> 初始全是宽区间，行为随机但有微弱倾向，像婴儿。

---

### 6.4 身体状态 Agent = 概率区间实时调节器

身体状态不必输出复杂生理数值，而是只输出：

- 对所有行为概率的 ± 偏移量
- 对整体区间宽度的缩放系数

示例规则：

- 精力高 → 理性行为概率↑，走神概率↓，区间收窄
- 精力低 → 走神概率↑，敷衍概率↑，烦躁概率↑，区间放宽
- 舒适值高 → 开心、话多、继续互动概率↑
- 舒适值低 → 抵触、结束对话、回避概率↑

推荐接口：

```yaml
body_probability_modulator:
  delta_vector: true
  interval_scale: true
```

---

### 6.5 关系模型 Agent = 最强概率收束器

关系状态不一定要先建复杂亲密度模型，v0.2 可直接把它作为社交行为约束器。

示例规则：

- 陌生人：礼貌概率拉高，撒娇/吐槽≈0，区间极窄
- 熟人：礼貌概率下降，随意/吐槽概率上升，区间放宽
- 亲密对象：放肆、撒娇、口是心非概率显著上升，区间最宽
- 被冒犯/失望：亲近行为概率骤降，冷漠/回避概率骤升

结论：

> 关系的本质，就是对社交行为概率的强收束或强释放。

---

### 6.6 情绪 Agent = 概率区间的突发扰动器

情绪不是固定状态，而是概率分布的短时扰动。

示例规则：

- 开心：正向行为区间整体上移
- 委屈 / 生气：负向行为区间突然拓宽
- 平静：行为概率回归基准线

结论：

> 情绪一来，置信区间瞬间被冲乱，像人突然失控。

---

### 6.7 DMN / 欲望 / 潜意识 = 小概率随机触发器

#### DMN
- 固定低概率触发
- 无聊时触发概率上升
- 插入跑题、联想、旧记忆片段

#### 欲望
- 摸鱼、想躺平、想舒适
- 精力低时概率上升
- 会拉低高成本行为

#### 潜意识
- 完全隐性
- 给所有行为候选加入微弱随机偏置
- 体现“莫名其妙”的好恶

结论：

> 人类的“莫名其妙”，本质上就是未被完全收束的底层随机。

---

### 6.8 海马体 Agent = 长期概率收束器

记忆在 v0.2 中不要求做复杂精确检索，它首先是一个**长期概率塑形器**。

作用规则：

- 高频经历 → 对应行为概率持续抬升
- 负面经历 → 对应行为概率持续压低
- 重复互动 → 行为越来越稳定，区间收窄
- 遗忘 → 概率慢慢回归基线，区间重新放宽

结论：

> 记忆的作用，是把短期随机慢慢固化成长期性格倾向。

---

### 6.9 丘脑调度 = 概率归一化 + 最终采样

所有 Agent 输出各自的：

- 概率偏移
- 区间缩放
- veto / suppress / boost 标记

丘脑只做一件事：

1. 汇总所有候选行为的概率向量  
2. 应用所有偏移与缩放  
3. 处理 veto  
4. 归一化  
5. 执行随机采样  
6. 选出一个行为候选  
7. 再交给输出层渲染成语言或动作  

可抽象为：

```text
P_final(action) = Normalize(
    P_base(action)
  + Δtemperament
  + Δbody
  + Δrelationship
  + Δemotion
  + Δdesire
  + Δdmn
  + Δunconscious
  + Δmemory
)
```

结论：

> 这一步同时解决多 Agent 冲突、夺权与混乱问题。

---

## 7. 置信区间收束规则（v0.2 核心）

系统只需要三条极简收束规律：

### 7.1 重复交互 → 区间收窄
越熟悉的人、越常发生的事，行为越稳定，随机空间越小。

### 7.2 负面体验 → 区间强制收窄
被伤害、被冒犯、失望，对应行为概率被快速锁定到更极端的范围。

### 7.3 空闲 / 低刺激 → 区间放宽
无聊、没事做、独处时，随机空间上升，走神、胡思乱想、自发行为概率上升。

最终形态：

- 对熟人：宽区间（自然、随意、有小意外）
- 对陌生人：窄区间（礼貌、稳定、可预测）
- 对自己：最随机（走神、发呆、内耗）

## 8. 初始性格：先天气质参数池

### 8.1 设计原则

系统启动时，不应被写死为某个固定“人设”，而应只具备一套**可波动的底层气质参数**，相当于人的天生秉性。

由：

- 潜意识 Agent
- 情绪 Agent

在启动时默认加载，作为唯一“出厂设置”。

这些参数：

- 不应被交互直接清零
- 不应被任意覆盖
- 只能被长期经历缓慢重塑

### 8.2 初始性格参数（极简版）

```yaml
temperament:
  extraversion: 0.45
  sensitivity: 0.72
  patience: 0.38
  attachment_need: 0.67
  boundary_softness: 0.41
  desire_priority: 0.76
  cognitive_bandwidth: 0.52
```

### 8.3 关键原则

初始性格是**倾向**，不是“定死的人设”。

> 初始性格是天生的脾气参数，不是写死的人设文案。

## 9. 初始记忆：空白人生 + 通用常识基底

### 9.1 个人情景记忆：从零开始

海马体 Agent 初始状态应为：

- 没有任何私人经历
- 没有和任何人的过往
- 没有专属回忆
- 没有“我和谁发生过什么”的记录

```yaml
episodic_memory:
  personal_episodes: []
  autobiographical_trace: []
  emotional_history: []
```

### 9.2 仅预装通用人类常识记忆

## 10. 性格、关系、记忆的生长闭环

### 10.1 初始记忆是如何产生的？

严格说，**初始个人记忆不预装**。  
第一条真正的个人记忆来自：

- 第一次显著互动
- 第一次强情绪波动
- 第一次关系变化
- 第一次身体状态剧烈变化

推荐记忆生成阈值：

```yaml
memory_write_gate:
  novelty_weight: 0.25
  emotional_salience_weight: 0.30
  relational_change_weight: 0.25
  body_impact_weight: 0.10
  task_relevance_weight: 0.10
  write_threshold: 0.55
```

### 10.2 性格是如何影响人际关系的？

性格不直接决定关系结果，而是决定：

- 更容易怎么解读别人
- 更容易对什么做出反应
- 更容易用什么方式靠近或疏远别人

关系更新公式：

```text
Δrelationship = event_valence
              × temperament_bias
              × emotional_state
              × reciprocity_signal
              × trust_modifier
```

### 10.3 如何通过交互攒记忆？

不是把每句话都存下来，而是把交互转成：

- 事件
- 情绪痕迹
- 关系变化
- 身体变化

只有满足条件，才会进入正式记忆。

记忆增长规则：

```yaml
memory_growth_rules:
  emotional_events_decay_slower: true
  repeated_events_strengthen_schema: true
  neutral_smalltalk_default_not_store: true
  relation_shift_events_priority_high: true
  body_disturbance_events_priority_high: true
  unused_memory_should_decay: true
```

## 11. 存储层设计

### 11.1 Working Memory

## 14. 单轮运行闭环

### Step 1：更新状态
输入到达后先更新：

- body_state
- emotion_state
- relationship_state
- unconscious bias

### Step 2：生成行为候选池
构建一组广谱候选行为，并给出初始宽区间概率。

### Step 3：各 Agent 输出概率偏移
- 身体：偏移 + 区间缩放
- 关系：社交约束
- 情绪：突发扰动
- 欲望：舒适偏置
- DMN：随机插入
- 潜意识：微弱偏差
- 海马体：长期惯性
- PFC：理性收束

### Step 4：海马体写入 / 检索
- segment event
- 根据 cues recall episodes
- 调整行为候选的长期权重

### Step 5：丘脑归一化 + 采样
- 汇总概率向量
- 应用 veto
- 归一化
- 采样一个行为候选

### Step 6：输出门禁
对被采样的行为做：

- body calibration
- emotion calibration
- relationship calibration

### Step 7：输出生成
主推理模型把被采样行为渲染为语言或动作。

### Step 8：写回状态
- 写 episodic memory
- 写 relation memory
- 写 emotional trace
- 更新 fatigue / inertia / expectation

## 20. 技术实现建议

### 20.1 强模型
只给两处：

- 主推理 / 输出生成器

### 20.2 小模型 / 规则

- Relationship：小模型 + 结构化状态机

- Unconscious：规则 + 随机偏置器

### 20.3 行为采样实现建议
优先用简单可控方案：

- 候选行为集合固定
- 各 Agent 输出 delta vector
- 丘脑做 softmax / tempered normalization
- 再执行一次随机采样

建议参数：

```yaml

  temperature: 0.85
  min_behavior_prob: 0.01
  max_behavior_prob: 0.70
  interval_relax_factor_idle: 1.20
  interval_shrink_factor_repeat: 0.85
```

## 22. v0.2 最关键的可行性判断

这一版比 v0.1 更可行的原因是：

1. **避免多 Agent 直接争执行权**  
   所有 Agent 只改概率，不直接拍板。

2. **保住随机性，但可控**  
   行为先随机，再被四因子收束，不会一开始就僵硬。

3. **容易落地为工程系统**  
   每个 Agent 输出统一 delta vector，丘脑统一归一化与采样。

4. **更接近活人**  
   活人的行为不是硬决策，而是概率受状态、关系、记忆、性格共同牵引。

## 23. 核心特征总结

这个系统的目标不是“更强 AI”，而是：

- 有驱动力分层
- 有多 Agent 博弈
- 有注意力分配
- 有状态影响输出
- 有先天气质
- 有空白人生
- 有记忆衰减与失真
- 有关系成长
- 有概率驱动行为
- 有置信区间收束
- 有 idle / sleep / auto-run 等长期运行机制

最关键的三条类人记忆原则：

1. **记不住全部，只能记住结构**  
2. **概括会反过来影响细节回忆**  
3. **会暂时忘记，但在足够好的线索下能想起来**

最关键的 v0.2 行为原则：

1. **先给全行为广谱随机概率**  
2. **再用身体、关系、性格、记忆四大因子持续收束**  
3. **最后由丘脑归一化并随机采样**  

最终一句话概括：

> 初始性格是天生的脾气参数，初始记忆是空白的人生白纸；行为先从宽区间随机开始，再被身体、关系、先天气质与记忆历史逐步收束，最终长成一个独一无二、像真人一样自然但不完美的长期运行主体。
